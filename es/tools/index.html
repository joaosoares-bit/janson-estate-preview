02 · HIPOTECA

Una cuota mensual, calculada con claridad

Indique el precio, la parte que financia, el tipo y el plazo. La cuota sigue la amortización francesa habitual: importe fijo, primero intereses y después capital.

El tipo puede ser fijo durante todo el plazo o variable, referenciado a un índice. Esta calculadora supone un tipo constante; un préstamo variable se moverá con el índice.
